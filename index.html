Receipt ledger

Every check appends one receipt. Each receipt hashes its input and report and carries the previous receipt's hash — edit a report later and verification fails; delete one and the chain breaks.

Built with Firebase AI Logic hybrid inference (Gemini Nano on-device + Gemini in the cloud), App Check, and Firestore. All AI inference goes through Firebase AI Logic. In demo mode a deterministic local engine stands in for the models and receipts are stamped DEMO.
